# ai-tooling

Tools for working with AI assistants, built and used at Anvil 43. Each tool lives in its own
directory with its own README.

| Tool | What it is |
|---|---|
| [`youtrack-mcp`](youtrack-mcp/README.md) | An MCP server that lets an assistant such as Claude Code find, read, create, comment on and update YouTrack issues. Java, stdio. |
